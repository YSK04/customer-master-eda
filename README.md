# Customer Master Exploratory Data Analysis (EDA)

An exploratory data analysis project examining customer data using Python (`pandas`, `matplotlib`, and `seaborn`) to explore distributions, regional/country patterns, and customer acquisition cost (`customer_acquisition_cost`).

## Project Structure
- `Analysis.ipynb`: Jupyter Notebook containing data exploration, summary tables, and visualizations.
- `customer_master.csv`: Customer dataset used for the analysis.

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
